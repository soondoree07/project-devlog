# 크몽 작가 포트폴리오 템플릿 — 기획서

작가포폴(jbae.art, `~/jbae-portfolio`)을 다른 작가가 쓸 수 있는 틀로 만들고,
설치·수정 가이드와 묶어 크몽 같은 프리랜서 사이트에서 판다.

## 정해진 것 (2026-10-26)

| 항목 | 결정 |
|---|---|
| 판매 형태 | **가이드형이 기본**: 템플릿 + 설치 가이드 + 도메인 구매·연결 가이드. 세팅 대행은 나중에 결정 |
| 도메인 | **고객이 자기 명의로 직접 구매**(가비아·Cloudflare 등). 없으면 무료 주소로 공개. 내 명의로 대신 사지 않는다(소유권·연장 책임) |
| 대상 | 화가 · 일러스트 · 사진 · 공예 — **2D 작품 위주**. 3D(입체 작품 여러 각도 등)는 보류 |
| 도록 | **포함** (인쇄 도록 내지 짜임 · 여러 권 구조) |
| 예시 사이트 | jbae.art 를 예시로 써도 됨. 판매 페이지 캡처에서는 이메일·인스타 등 개인정보를 지운다 |
| 원본 | `~/jbae-portfolio` 는 건드리지 않는다. 복사본에서 작가 정보를 걷어내 틀을 만든다 |

## 열린 질문

1. **고객이 비밀번호로 들어와 작품을 추가·수정하는 관리 화면** — 만들지, 어떤 방식으로 만들지
2. 호스팅 — 지금 jbae.art 는 GitHub Pages. 관리 화면을 넣으면 서버 기능이 있는 곳(Cloudflare Pages 등)이 필요할 수 있다
3. 크몽 규정 — 디지털 파일 판매 카테고리, 거래 후 외부 연락·결제 금지 조항 확인
4. 가격 · 상품 단계

## 원본에서 걷어낼 것

- `data.json` 의 작가 정보 · 작품 · 약력 · 연락처
- `images/` 작품 사진, `catalogs/` 도록 데이터, QR, `CNAME`, 파비콘 · 공유 미리보기 이미지
- 배정혜 전용 문구(작품 연보 안내 줄 등)
