# 크몽 작가 포트폴리오 템플릿 — 기획서

작가포폴(jbae.art, `~/jbae-portfolio`)을 다른 작가가 쓸 수 있는 틀로 만들고,
설치·수정 가이드와 묶어 크몽 같은 프리랜서 사이트에서 판다.

## 정해진 것 (2026-10-26)

| 항목 | 결정 |
|---|---|
| 판매 형태 | **완성 대행이 주력**(2026-10-26 변경): 자료를 받아 내가 작품·약력을 입력해 사이트 완성. 템플릿 + 가이드는 그 바탕이자 하위 상품 |
| 도메인 | **고객이 자기 명의로 직접 구매**(가비아·Cloudflare 등). 없으면 무료 주소로 공개. 내 명의로 대신 사지 않는다(소유권·연장 책임) |
| 대상 | 화가 · 일러스트 · 사진 · 공예 — **2D 작품 위주**. 3D(입체 작품 여러 각도 등)는 보류 |
| 도록 | **포함** (인쇄 도록 내지 짜임 · 여러 권 구조) |
| 예시 사이트 | **실제 이용 사례 = 배정혜 작가 jbae.art (작가 허락 받음, 2026-10-26)** — 이메일 · 인스타 등 개인정보는 빼고 보여 준다. **템플릿 샘플(데모) = 빈센트 반 고흐 명화** |
| QR 코드 (2026-10-26) | **사이트 QR 은 내가 만들어 준다** — 이미지 파일로 따로 주고, 도록 상품이면 **도록 뒤표지에도 붙인다**. **인스타그램 QR 은 고객이 인스타 앱에서 만들어 보내 주면** 도록 뒤표지에 넣어 준다 |
| 샘플 명화 저작권 | 고흐(1890 사망)는 사후 70년이 지나 작품 저작권이 끝났다. 쓴 이미지 25장은 위키미디어 공용 기준 퍼블릭 도메인 24장 · CC0 1장(메트로폴리탄). 평면 명화를 그대로 찍은 사진은 새 저작물로 보지 않는 게 미국 · 한국 · EU(2019 디지털 단일시장 지침 14조) 흐름. 바닥글에 출처를 적어 둔다 |
| 원본 | `~/jbae-portfolio` 는 건드리지 않는다. 복사본에서 작가 정보를 걷어내 틀을 만든다 |

## 기록 메뉴 (2026-10-30 추가)

- 작가 사이트에는 작품 말고도 글이 계속 쌓인다(지인 조언) → 머리띠 **'기록'**(영어 Archive) 메뉴. '글'은 너무 대놓고라 바꿈
- 종류: 작가노트 · 평론 · 전시 서문 · 기사(원문 링크). 글마다 사진 1장(선택)
- 첫 화면: 히어로 → **작가 소개 + 인용 한 구절** → 작품 → 약력 → 문의. 머리띠도 작가 · 작품 순서
- 기록이 없는 주문은 도록처럼 메뉴가 빠진다. jbae.art 에도 틀만 넣고 숨김
- 도록에는 따로 작가 소개 쪽이 없고 작가노트(서문) · 약력 쪽이 그 역할 — 기록의 작가노트를 도록에도 그대로 쓴다
- **상품별 글 수 확정 (2026-10-30)**: 기본 3 · 도록 5 · 프리미엄 10편. 넘거나 구매 확정 뒤 추가는 1편 1만 원. 평론 · 기사는 글쓴이 · 언론사 허락을 작가가 받는다(어려우면 앞부분 + 원문 주소)

## 관리 화면 없음 (2026-10-26 변경)

- **고객이 직접 작품을 추가하는 기능은 넣지 않는다.** 가이드·판매 페이지에도 쓰지 않는다
- 사이트는 정적 파일만(KV · `_worker.js` 불필요)

## 호스팅 · 설치 흐름 (2026-10-26 결정)

- **고객 명의 Cloudflare 계정 + 나를 멤버로 초대.** 비밀번호는 받지 않는다. 고객은 언제든 초대를 취소할 수 있다
- **고객이 하는 일은 세 가지뿐**: ① Cloudflare 가입 ② 나를 멤버로 초대 ③ 가비아에서 네임서버 변경 (+ 도메인 구매)
- 사이트 파일 올리기 · 도메인 추가 · 연결은 **내가 멤버 권한으로 내 컴퓨터에서** 한다. 고객은 올리는 과정을 보지 않는다
- **원격 지원 · 통화는 하지 않는다 (2026-10-26 결정).** 고객은 가이드 PDF 를 보고 따라 하고, 막히면 화면 캡처를 크몽 메시지로 보내 같이 푼다. 비밀번호 · 결제 · 인증 번호는 받지 않는다
- GitHub Pages 를 안 쓰는 이유: 무료는 저장소 공개라 템플릿 코드가 노출된다

- 기간: **기본 7일, 도록 10일, 프리미엄 14일** (2026-10-27 변경, 경쟁자 5 · 7 · 10일과 맞춤). 기간이 결제일부터라 자료는 **결제 전에** 받는다 — 문의 때 자료 요청서 · 무드 견본을 보낸다
- 전문가 소개: 가족 관계 없이 "화가 배정혜 작가의 사이트와 도록을 만들었다"로

## 크몽 조사 (2026-10-26)

- 거래 전 개인 연락처 공유·요청 금지, 크몽 밖 직접 결제 금지. 설명란 연락처·SNS 는 승인 거부 사례
- 판매 수수료 = 구간별 서비스 이용료(70만 원까지 16.4% · 다음 130만 원 9.4% · 그 위 4.4%) + 결제망 3.3% + 둘의 부가세. 50만 원이면 정산 약 39만 원
- 크몽 홈페이지 제작 거래가: 최저 8만 · 평균 69만 · 최고 180만 원(2025-09 공지)
- 경쟁: 아임웹 · 윅스 대행 10만~80만 원(웹빌더 월 요금 별도), 맞춤 제작 130만~440만 원
- 차별점: 호스팅 0원(도메인만 연 1~3만 원), 작가 전용 디자인, 인쇄 도록 화면, 한국어 관리 화면
