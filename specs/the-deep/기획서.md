## 1. 한 줄 요약
해안가(수심 0m)에서 시작해 마리아나 해구(약 11,000m)까지 **아래로만** 내려가며, 각 수심대에 사는 생물과 대표 구조물을 보여주는 세로 스크롤 사이트.

## 2. 핵심 컨셉
- 시작은 **수심 0m 해안가**, 아래로 스크롤할수록 깊어진다 (한 방향)
- 각 수심에 **의미 있는 구조물** 배치 (타이타닉 잔해, 노르트스트림 가스관, 챌린저 해연 등)
- 각 구간에 **대표 생물을 일러스트로** 배치, 같은 위치에서 무한루프로 움직임
- **영어 / 한국어 전환** 지원 — 접속 지역에 맞춰 자동으로 시작
- **낮/밤 전환** — 약광층 생물이 밤에 표층으로 올라오는 일주 수직 이동을 반영

> **2026-07-25 방향 전환**: 원래 하늘↔바다 양방향 `deep-and-high`였으나 바다(아래) 한 방향만 남기고 이름을 **The Deep**으로 통일. 하늘 밴드(up-a~up-f)·research-up 삭제.

## 3. 기술 스택 (2026-07-27 확정)
| 영역 | 선택 |
|---|---|
| 프레임워크 | **Next.js 16** (App Router · TypeScript) |
| 스타일링 | **CSS Modules + 전역 CSS** — 스크롤 커스텀 애니메이션이 핵심이라 순수 CSS |
| 데이터 | `docs/bands/*.md` → `src/data/bands.json` (`npm run build:bands`) |
| 언어 | 접속 지역 자동 감지(`src/proxy.ts`) → 사용자 선택은 쿠키 우선. URL은 `/` 하나 |
| 일러스트 | 방식 미정 (149종 전부는 비현실적, 대표종 추림 필요) |
| 호스팅 | 미정 (Vercel이면 접속 국가 헤더가 그대로 동작) |

> ⚠️ **Next 16부터 `middleware.ts`가 `proxy.ts`로 개명됐다.** 코드 작성 전 `node_modules/next/dist/docs/` 확인 (프로젝트 `AGENTS.md` 지시).

**Vanilla JS 대신 Next.js를 고른 이유** — 사용자 결정. 도감형으로 정보량·상호작용이 커질 여지와 컴포넌트 재사용·이미지 최적화·SEO를 우선했다.

## 5. 데이터 파이프라인 (2026-07-27 완료)
```
docs/bands/*.md  ──(npm run build:bands)──>  src/data/bands.json
     원본                                          산출물
```
데이터를 고칠 때는 **md를 고치고 다시 돌린다.** JSON은 직접 수정하지 않는다.

**변환기 구성** — `scripts/build-bands.mjs`(진입점) + `scripts/bands/`(표 파서 · 수심 해석 · 엔트리 매핑)

**수심 표기를 구분해 담는다**: `approximate`(약 ~) · `tolerance`(±) · `deepestRecord`(최심 관측 기록) · `orDeeper`(이상 +) · `retracted`(철회된 기록, 취소선) · `outOfBand`(밴드 밖 참조)

**데이터 정직성 규칙 (코드에 반영됨)**
- 한국어 국명 없는 종 → `ko: null` + `hasKoreanName: false`. 임의 번역하지 않는다
- 밤 수심(`diel.nightDepth`)은 **표에 명시된 종만** 채운다. 서술로만 "밤에 올라온다"는 종은 `migratesAtNight: true` + `nightDepth: null`
- 숫자로 못 옮긴 4건(모호면 · 콜라 초심층 시추공 · 해구 퇴적층 미생물 · 밴드 밖 대왕등각류)은 `min: null` + 원문 유지

## 6. 스크롤 설계 근거 (리서치에서 도출)
- **스크롤 200px = 일정 깊이가 아님.** 항목 밀도에 따라 구간별 깊이를 다르게 배분
- **0m 바로 아래가 가장 붐빈다(55종)** → 위쪽은 느리게·빽빽하게, 아래로 갈수록 빠르게
- **절벽 2곳** — 수심 200m(광합성 끝, 식물 소멸) / 수심 8,400m(척추동물 끝)
- **03은 "어둠+점" 구조** — 심해평원 대비 열수분출공 생물 밀도차 약 10만 배
- **상주 vs 통과** — 제자리 루프(상주) / 가로질러 지나가는 루프(통과)로 애니메이션 분기
- **02는 낮/밤에 생물 구성이 통째로 뒤바뀐다** — DSL이 밤에 표층까지 올라옴
