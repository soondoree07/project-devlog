## 1. 개요

게임·애니 음악의 **선율만 가져와** 수면용 피아노로 새로 편곡하고, 고흐 유화풍 그림과 함께
8시간 영상으로 올린다. 영어권 대상. 첫 IP 는 메이플스토리.

| | |
|---|---|
| 채널 | `Save Point Sleep` (핸들 `@savepointsleep` 예정) |
| 저장소 | `~/save-point-sleep` (로컬 커밋만) |
| 자매 채널 | Hushed Places ASMR — 자연 소리 (`~/sleep-asmr`) |

### 이름 조사 (2026-09-21)

유튜브 핸들 `@savepointsleep`·`@SavePointSleep` 페이지 없음 · `savepointsleep.com`/`.net` 미등록 ·
같은 이름 채널·브랜드 못 찾음(비슷한 SavePoint 류는 일반 게임 채널).
인스타·틱톡·X·상표는 확인하지 않았다. 같은 분야 경쟁 = GameChops(`X & Sleep`), Super Piano 64.

### IP 선정 기준

곡을 만들기 전에 권리자가 **음악 2차 창작 유튜브 수익화**를 허락하는지 먼저 확인한다.
동방·넥슨·라이엇(크리에이터 세이프 곡)은 허용, FF14·호요버스·닌텐도·포켓몬은 불가 (2026-09-20 조사).

## 2. 메이플스토리

자세한 내용은 저장소 `README.md` 와 `docs/권리정리.md` 에 있다. 여기는 요약이다.

### 2.1 권리 — 권리자가 둘이다

| | 누구 | 쓸 수 있나 |
|---|---|---|
| 작곡(선율) | 넥슨 | **된다** — 게임IP사용가이드 |
| **편곡** | **유리글(LEEGLE)** | **안 된다** — 넥슨이 제3자 편곡까지 허락할 수는 없다 |
| 음원(녹음물) | 넥슨 | 안 쓴다 — Content ID 가 녹음물 지문에 걸린다 |

가진 악보(`E:\악보\`)는 유리글 편곡본이다. 판면에 `편곡 유리글 (LEEGLE)` 이 박혀 있다.
유리글은 메이플 BGM 대부분을 피아노 솔로로 편곡해 **악보를 파는** 사람이다.

**그래서 선율만 가져오고 화성·반주 음형·템포는 새로 만든다.**

⚠️ **템포만 낮추는 것은 아무 의미가 없다.** 템포는 저작물이 아니라 느려진 유리글 편곡이 될 뿐이다.
수면용으로 가면 어차피 갈아치워야 한다(유리글 판본은 `Allegro cantabile` 연주회용).
권리상 안전한 길과 음악적으로 맞는 길이 같은 방향이다.

**Suno 는 안 쓴다** — 업로드하면 "모든 권리를 갖고 있다"고 보증하고 영구·취소 불가
라이선스를 준다. 악보·MIDI 입력도 안 받아 우회가 없다.

### 2.2 공정

| 단계 | 스크립트 | 실측 |
|---|---|---|
| 악보 → MusicXML | `run_omr.py` (Audiveris 5.11) | **4쪽 29초** → 240곡 약 2시간 |
| 선율 추출 | `melody.py` | 최고음 + 같은 음 되풀이 합치기 |
| 수면용 편곡 | `arrange.py` | 화성·반주·템포·리듬을 새로 |
| 소리 | `sampler.py` (기본) / `synth.py` (임시) | Salamander Grand Piano V3 |

악보는 **벡터 PDF**(Microsoft Print to PDF)라 스캔보다 OMR 정확도가 높다.

### 2.3 정한 값 (엘리니아 기준)

- **빠르기** 한 박 0.6초 = 100bpm. 1.6초는 너무 느렸다
- **리듬** `original` — 악보에 붙임줄이 없고 점8분+16분이 100%(0.75 52개 / 0.25 51개).
  같은 음을 두 번 치는 되풀이가 원곡의 특징이다
- **화성** B-flat 장조 다이어토닉 7화음
- **왼손** 선율은 박 위에, 분산화음은 박 사이에. 저음은 마디 첫 박 근음 하나만
- **소리 크기** `-23 LUFS` — 자매 채널(Hushed Places)과 같다
- **세기** 16단계 중 **2~5단계**만. 세게 친 샘플을 작게 틀면 밝고 찌른다 (2026-09-23)
- **사람 손** `performance.py` — 시점 ±8ms · 세기 ±6% · 프레이즈 셈여림 · 4마디째 느려짐 · 마디 페달. 잔향 28%

곡마다 정한 값은 `docs/곡별설정.md` 에 적는다.

### 2.4 유튜브 설정 — 자연음과 반대다

- **AI 공개 = "아니요"** (음악이 AI 생성물이 아니고 화면도 비사실적 유화)
- 설명에 **넥슨 공식 채널 또는 네코드뮤직 링크** (가이드 요구사항)
- 설명에 **Salamander Grand Piano V3 by Alexander Holm (CC-BY 3.0)** (샘플 라이선스)
- 제목에 `MapleStory` — 예: `8 Hours in Henesys at Night | MapleStory Music for Sleep`

## 3. 리스크

| 위험 | 대응 |
|---|---|
| 제3자 편곡 저작권 | 유리글 악보는 선율 읽기에만. 화성·반주·템포는 새로 |
| 게임 IP 허락 취소 | 넥슨은 언제든 취소할 수 있다 — 다른 IP 로 넓혀 채널이 한 IP 에 묶이지 않게 한다 |
| Content ID | 녹음물은 새로 렌더하므로 지문에 안 걸린다. 작곡 매칭이 생기면 이의 제기 |
| 진정성 없는 콘텐츠 정책 | 편마다 그림·편곡·장소가 달라야 한다 |
| Suno 등 생성 AI | 원곡 업로드 약관 위험 — 안 쓴다 |
