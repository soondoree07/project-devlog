## 1. 개요

10시간 단위 자연 환경음 영상을 제작해 유튜브에 업로드하는 롱폼 채널.

**핵심 기법:** 오디오 레이어의 길이를 서로 다른 소수(prime)로 지정해 겹치면,
전체 반복 주기가 약 60시간이 되어 10시간 영상 안에서 루프가 인지되지 않는다.

**기존 ASMR 쇼츠 채널과 분리 운영.** 유리 커팅·구리 와이어 미니어처는 시각형
쇼츠고 이 채널은 청각 중심 롱폼이다. 시청 목적, 세션 길이, 알고리즘 신호가
달라 한 채널에 섞으면 추천이 흐려진다.

---

## 2. 시장 근거

**확인된 사실**

- 미국 성인 8%가 잠들기 위해 ASMR에 의존 (화이트노이즈 15%, 수면 팟캐스트 11%)
- ASMR 이용자 내부에서는 수면이 최다 용도 — 82%
- 미국 성인 약 31%가 잠드는 것에 대해 걱정 → 잠재 시장 큼

**주의**

- ASMR 수면 이용자 조사(n=464): 81.9% 여성, 평균 26.2세. **노년층 타겟 아님**
- 성공적 이용자 상당수가 화면을 보지 않고 오디오 전용으로 소비
  → 영상은 "틀어놓는 것"이지 "보는 것"이 아니라는 전제로 설계

**핵심 지표는 조회수가 아니라 총 시청 시간이다.**

## 4. ElevenLabs 운영

### 4.1 결제

| 항목 | 결정 |
|---|---|
| 플랜 | Creator (첫 달 50% $11, 이후 $22) |
| 사업자 | "비즈니스 목적으로 구매합니다" **체크 해제** — 개인 결제 |
| BRN | 입력 불필요 (체크 해제 시 칸 사라짐) |
| 해지 | 결제 직후 **자동 갱신 해지 예약** (다운그레이드 아님) |

**한 달 전략의 근거**

- 유료 구독 중 생성한 콘텐츠는 구독 종료 후에도 **영구 상업 이용 가능**
- 다운그레이드해도 이미 만든 오디오의 상업권은 유지
- 이후 새로 생성하는 것만 무료 플랜 제약(비상업, 출처 표기) 적용
- 상업 라이선스의 최소 조건은 Starter($6). Creator는 크레딧 양 때문에 선택

**크레딧은 이월·환불되지 않는다. 한 달 안에 소진해야 한다.**

### 4.2 생성 설정 (고정)

| 설정 | 값 | 이유 |
|---|---|---|
| Duration | **직접 지정, 소수점 없이** | 자동은 200 크레딧 고정 + 길이 통제 불가 |
| Looping | **On** | 심리스 루프. 끄면 이음매 복구 불가 |
| Prompt influence | **90%** | 프롬프트 문자 그대로 해석 |
| Explore 공유 | **Disable** | 켜두면 생성물이 공개돼 타인이 그대로 사용 |
| 다운로드 | **WAV 48kHz** | MP3 금지 |
| 변형 | **4개 전량 다운로드** | 크레딧은 이미 소진됨 |

**WAV 사용 근거:** 레이어를 4~5개 겹치고 반복 복제하고 크로스페이드를 거는
구조라 MP3 손실이 누적된다. 빗소리·나뭇잎·바람 같은 고주파 노이즈가 특히
취약. 최종 인코딩이 AAC이므로 MP3→AAC는 손실 2회, WAV→AAC는 1회.
48kHz는 영상 표준이라 리샘플링이 발생하지 않는다.

### 4.3 크레딧 (총량 실측 기준)

루프 모드에서는 공식 요금표의 초당 40 크레딧이 적용되지 않는다.

처음에는 표본 1개(29초 = 388)로 **초당 13.38**을 가정했는데, A·B·D 50개를
다 뽑고 나니 실제로는 훨씬 덜 들었다.

**총량 실측 (2026-09-07)** — 121,000 → 잔액 110,984, 소모 **10,016**.
생성 1,200초 + 재생성 약 132초 기준 **초당 약 7.52**.
표본 1개 모델의 **56%**다. 총량 실측이 더 믿을 만하므로 이 값을 쓴다.

| 항목 | 개수 | 총 길이 | 크레딧 | 상태 |
|---|---|---|---|---|
| 그룹 A + B + D | 50 | 1,200s | 10,016 (실측, 재생성 포함) | 완료 |
| 그룹 C | 88 | 2,288s | 17,205 (추정) | 미착수 |
| **합계** | | | **27,221** | |
| Creator 총량 | | | 121,000 | |
| **현재 잔액** | | | **110,984** | |
| **그룹 C까지 쓰고 남는 양** | | | **93,779** | |

그룹 D 내역: 슬라임 동굴 69s(29+23+17) · 마왕성 71s(29+23+19) ·
얼음성 69s · 오래된 대저택 71s.

잔액은 초당 7.52 기준 **약 280장면** 분량이다.
**크레딧은 제약이 아니다.** 진짜 제약은 청취 검수에 드는 사람 시간이고,
그룹 C만 해도 변형 포함 352개 파일을 들어야 한다.

**변형 4개는 추가 비용이 아니다.** 1회 생성에 포함되므로 실질 소스는
레이어 수 × 4다.

폐기된 A14·A20은 위 계산에서 빠져 있다.

## 5. 레이어 사양

**길이는 소수만 사용: 13 / 17 / 19 / 23 / 29초**

검증: 29 × 23 × 19 × 17 = 215,441초 ≈ **59.8시간**
→ 10시간 영상 안에서 전체 레이어가 같은 위치로 돌아오지 않는다.

### 5.1 프롬프트 작성 규칙 9종

**프롬프트 원본과 규칙 전문은 `CHECKLIST.md` 0장.** 여기서는 목록만 둔다.

| # | 규칙 | 요약 |
|---|---|---|
| 1 | 약화 키워드 2개 이상 금지 | `soft`+`low intensity` 조합으로 A08이 무음화됨. `silent`가 든 B17도 동일 |
| 2 | 정체성 금지 금지 | 불은 crackle, 대나무는 knocking. `no pops` 대신 `gentle pops only` |
| 3 | 거리감 ≠ 볼륨 | 거리는 공기 흡수 + 반향이 만든다. 볼륨만 낮추면 "작게 녹음된 가까운 소리" |
| 4 | 연속성 명시 통제 | `continuous`는 통짜 노이즈를 만든다. 액센트는 `individual … long gaps` |
| 5 | 배제 키워드 | `no metal` `no gravel` `no sharp taps` `no whistling` `no shrieking` 등 |
| 6 | **히스 계열 공식** | 물·바람·잎·모래·천은 본질이 고역 노이즈 |
| 7 | **트랜지언트 계열 공식** | 불·물방울·시계·종·나무는 파열음 |
| 8 | 기계음 회피 | `drone`·`hum`은 신디사이저를 부른다. 물리적 질량감으로 표현 (B05 사례) |
| 9 | 마찰음은 벽 하나 뒤로 | 삐걱임은 근접하면 고역이 튄다. `heard from another room` (B16 사례) |

**규칙 6 공식** — `heard from a distance, deep and rounded, high frequencies absorbed by air, muffled, no hiss, no fizz`
`no hiss`만으로는 부족하다. 거리 + 공기흡수 + 뭉갬 셋이 함께여야 한다.
해당: B03 B04 B07 B08 B12 B14 B17 B18 B20 D08

**규칙 7 공식** — `deep and rounded, muffled, gentle onset, long decay, no sharp attack`
종은 `warm fundamental only, no bright overtones, no metallic ring`.
얼음은 `glassy`·`crystalline` 사용 금지 — 고역을 직접 지시하는 단어다.
해당: A18 A19 B11 B16 D02 D03 D05 D06 D11 D12

**핵심 원리:** 아픈 건 음원이 아니라 **부딪히는 표면**이다.

### 5.3 그룹 D — 판타지 컨셉 (완료)

**전제: 공포물이 아니라 조용한 ASMR이다.** 비명·괴물·위협적 음향 전부 배제.
"그 공간에 혼자 조용히 있는 느낌"이 목표.
공통 문구: `calm, peaceful, no menace, no screams, no monsters`

| 컨셉 | 레이어 | 재사용 |
|---|---|---|
| 슬라임 동굴 | D01 base / D02 ooze / D03 drip | A19, B19, B20 |
| 마왕성 | D04 hall / D05 torch / D06 bell | A09, B19 |
| 얼음성 | D07 hall / D08 wind / D09 settle | A11 |
| 오래된 대저택 | D10 room / D11 clock / D12 fireplace | B16, A01, A02 |

**전략적 이점:** 병목은 영상인데 판타지는 여기서 유리하다. 자연 장면은 실사
고증이 필요해 AI 생성물의 어색함이 드러나지만, 판타지는 고증할 원본이 없어서
Higgsfield 생성물이 그대로 완성품이 된다. 검색어 경쟁도 얕다.

**주의:** 게임·영화 IP와 겹치기 쉽다. 특정 작품을 연상시키는 명칭이나 비주얼은
피하고 일반명사로만 간다.

시간대 축(새벽/낮/밤)은 적용하지 않는다. 실내 공간이라 무의미하다.

**생성 결과** — 29초 배경 4개(D01·D04·D07·D10)가 거의 들리지 않게 나와
믹싱에서 볼륨을 올려 쓴다(6.2). B15·B17에서 겪은 것과 같은 현상이라
재생성이 아니라 볼륨으로 잡는다. D09는 `deep low groans` 유무로
프롬프트 2종을 만들어 소스 5개를 확보했다. 상세는 CHECKLIST.md.

### 5.4 그룹 C — 확장 베이스 (프롬프트 작성 완료)

44장면 × (베이스 29s + 서브 23s) = 88개. 규칙 1~9를 적용해 작성했고
프롬프트 원본은 CHECKLIST.md에 있다. 생성은 미착수.

기획서 원안 34장면에, 게임 환경 조사(마인크래프트 바이옴 · 젤다 지역 ·
포켓몬 지방 · 스카이림 · 원신)로 찾은 **신규 10장면**을 더했다.

| 신규 장면 | 출처 | 왜 필요한가 |
|---|---|---|
| 온천 | 젤다 라넬, 포켓몬 | 물이 끓는 소리가 48장면에 하나도 없었다 |
| 폐광 갱도 | 마인크래프트, 스카이림 | 동굴과 다르다. 나무 지지대 + 좁은 반향 |
| 비 오는 창가 | — | A05는 텐트 지붕이다. 유리창은 질감이 다르고 검색량 최상위 |
| 얼어붙은 호수 | 마인크래프트, 젤다 | D09 얼음 정착음 경험이 그대로 쓰인다 |
| 폭포 뒤 동굴 | 젤다 조라의 샘 | 폭포·동굴이 따로 있는데 이 조합이 없었다 |
| 대성당 | 스카이림, 젤다 신전 | 오래된 성보다 반향이 훨씬 크다 |
| 지하 와인 저장고 | 스카이림, 스타듀 | 다락방의 지하 버전 |
| 꽃밭 | 포켓몬 꽃길, 원신 | 벌 소리가 없었다. 단 4~6kHz라 거리 필수 |
| 사바나 밤 | 마인크래프트, 포켓몬 | 초원과 달리 마른 풀 + 먼 동물 |
| 캠핑카 안 비 | — | 야영지의 차량 버전. 수요 대비 공급이 적다 |

**제외한 것** — 지하철·도시 골목은 기획서 13장이 이미 배제했다.
우주정거장·비행선류는 규칙 8(기계음 금지)에 정면으로 걸린다.
안개 낀 숲·자작나무 숲은 소리로는 기존 숲과 구분이 안 된다.

**계열 구성** — 물 11 · 숲 5 · 건조·평원 7 · 고지·한대 6 · 인공 공간 15장면.

**고위험 5장면** — 폭포 · 계곡 · 화산지대 · 기차 안 · 항구.
전부 고역 노이즈나 금속 마찰이 본질이라 규칙 6 공식이 필수다.

**베이스 가청성** — 그룹 D의 29초 배경 4개가 거의 안 들린 사고를 겪었으므로,
그룹 C 베이스 전체에 `clearly audible` / `audible body`를 넣고 규칙 1 약화
키워드를 걷어냈다. 배경음은 "여기가 어디인지" 알아들을 정도로는 나와야 한다.

인공 공간부터 시작하는 게 유리하다 — 실내는 반향으로 거리감을 만들기 쉽고
그룹 D에서 같은 문법을 이미 검증했다.

### 5.5 시간대 축

| 밤 | A15 frogs 또는 A16 owl — 또는 없음 |

A14 폐기로 밤이 2갈래로 나뉘어 경우의 수는 오히려 늘었다.
사막 밤처럼 둘 다 안 맞는 장면은 **생물 레이어 없이** 3레이어로 간다.

장면별 실제 배정은 `data/scenes.json`의 `timeLayers`에 있다.

## 6. 믹싱

### 6.1 표준 구성

```
베이스     29s    볼륨 100%    패닝 중앙
서브베이스 23s    볼륨 60-70%  패닝 중앙
날씨       13-29s 볼륨 40-80%  패닝 좌 20%
생물       17-29s 볼륨 20-40%  패닝 우 20%
액센트     17-19s 볼륨 15-25%  패닝 좌우 교대
```

**고역 위험 레이어(A13 / A17 / B10)는 볼륨 상한 25%.**

### 6.2 레이어별 볼륨 보정 (그룹 B 검수 반영)

표준 비율에 아래 보정을 더한다.

| 방향 | 대상 |
|---|---|
| **낮춤** | B06 · B14 · B19 · B20 · D06 |
| **올림** | B15 · B17 · B12(변형 1·2·4) · D01 · D04 · D07 · D10 · D08(변형 1·2) |

- B15·B17은 룸톤·저역 계열이라 원래 작게 나온다. 볼륨을 올리되
  노이즈 플로어가 따라 올라오면 Low-pass를 8kHz까지 내려 잡는다.
- B12는 변형별 편차가 크다. 하나를 고르지 말고 서로 다른 시작점에서
  2개를 겹치면 밀도가 좋아진다.
- **D01·D04·D07·D10은 그룹 D의 29초 배경 전체다.** 넷 다 거의 들리지 않게
  나왔다. 공간 앰비언스 계열은 원래 작게 나온다고 보고, 다음 그룹에서도
  볼륨으로 잡을 것을 전제하고 간다.

### 6.3 EQ·다이내믹 안전장치

| 처리 | 설정 | 대상 |
|---|---|---|
| Low-pass | 8~10kHz, 12dB/oct | **전 레이어 (필수 기본)** |
| Low-pass | 3~4kHz | 거리감이 필요한 액센트 |
| High shelf 감쇠 | 5kHz 이상 -3~6dB | 새·모래 |
| Reverb | Room 크게, wet 30~40% | 거리감 보정 |
| Limiter | -12dB 천장 | 불·물방울 |
| Compressor | 2:1, 느린 어택 | 파도·천둥 |

Low-pass 전역 적용은 선택이 아니다. 자연음의 8kHz 이상 성분은 수면
콘텐츠에서 정보량이 거의 없고 피로만 준다.

### 6.4 Audacity 작업 순서

1. 트랙 5개 배치
2. **전 트랙 Low-pass 8~10kHz 적용** (6.3)
3. 볼륨 설정 — 표준 비율(6.1) + 레이어별 보정(6.2) + 고역 위험 25% 상한
4. 패닝 적용
5. 위험 레이어에 High shelf 감쇠 / Limiter / Compressor (6.3)
6. 각 트랙을 30분까지 반복 복제, 이음매마다 2~3초 크로스페이드
7. 30분 마스터 렌더 (WAV 48kHz)
8. 마스터를 20회 반복해 10시간

2~5단계는 사람이 매번 기억할 수 없다. `mix_layers`가 `scenes.json`의
`mixTemplate`을 읽어 강제해야 한다.

### 6.5 재조립이라는 선택지

재생성 전에 **기존 4개 변형에서 좋은 구간만 뽑아 재배치**하는 방법이 있다.

A17(갈매기)이 이 방식으로 해결됐다. 19초 중 7.6~13.6초 구간만 멀고
조용했고, 그 안의 울음 5개를 19초 안에 불규칙 간격(1.6 / 5.1 / 8.4 /
12.2 / 15.9초)으로 재배치해 루프 안전본을 만들었다.

**양 끝을 무음으로 두면 이음매가 자동으로 깨끗해진다.**
크레딧도 아끼고 결과도 나은 경우가 많다.

자동화 스펙은 `scripts/reassemble.py`.

## 7. 영상

**정지 이미지 1장으로 10시간은 금지.** 수익화 정책 위반 위험 (8장).

- Higgsfield로 짧은 루프 영상 제작
- 또는 이미지-투-비디오로 5~10초 미세 움직임 후 크로스페이드
- **시간대별 밝기를 서서히 변화**시켜 "10시간에 걸쳐 해가 지는" 구조로
  만들면 구조적으로 반복이 아니게 됨 → 정책 리스크 대폭 감소

**날씨·시간대 변형은 영상 재제작 불필요.** 색보정 + 오버레이(비 입자,
눈 입자)로 대응한다. 새로 만들어야 하는 영상은 **베이스 장면 수만큼**이다.

### 인코딩

```
코덱: H.265
프레임레이트: 24fps 이하
CRF: 28-30
오디오: AAC 192kbps
```

화면 변화가 적어 압축률이 매우 좋다. 10시간 1080p 기준 20~60GB → **5~10GB**.

## 8. 리스크 — 수익화

유튜브 파트너 프로그램은 반복적이고 최소한의 변형만 가한 콘텐츠를 수익화

```
│   ├── reassemble.py          ← 변형에서 좋은 구간 추출·재배치 (6.5)
│   └── encode.py              ← ffmpeg H.265 배치 인코딩
├── data/

```

**오디오·영상 파일은 git에 넣지 않는다** (`.gitignore`). 용량 때문이다.
원본 WAV는 로컬 이중 백업으로 관리한다.
다운로드 작업 폴더는 바탕화면 `그룹 A` / `그룹 B` 아래 레이어별 폴더.

### 파일명 규칙

```
{그룹번호}_{이름}_{길이}s_v{변형번호}.wav
A01_rain_light_29s_v1.wav
```

### 자동화 우선순위

1. **extend_loop** — 29초 → 30분. Audacity 수작업의 최대 병목
2. **mix_layers** — scenes.json 기반 합성. 6.1~6.3 자동 적용
3. **build_10h** — 30분 마스터 20회 이어붙임
4. **reassemble** — RMS 분석으로 조용한 구간 탐지 후 재배치
5. **encode** — 오디오 + 영상 병합 후 배치 인코딩

1~3이 자동화되면 장면 1개 제작 시간이 수십 분에서 수 분으로 줄어든다.

## 10. 경우의 수

### 1단계 (베이스 10개)

10 장면 × 5 날씨 × 3~4 시간대 = 150~200
→ 물리적 불가 조합 제외 시 **유효 99개** (`scenes.json`에서 계산됨)

### 2단계 (그룹 D 포함, 베이스 14개)

D 4장면을 더하면 **유효 107개**. 길이 변형 3종(3시간 / 8시간 / 10시간)을
곱하면 **321편**.

### 3단계 (그룹 C 확장)

크레딧상 베이스 139개 추가 가능 → 이론상 1,000편 이상

### 실제 제약

경우의 수는 오디오 기준이다. **병목은 영상이다.**
새로 만들어야 하는 영상 수 = 베이스 장면 수 (현재 14개).

## 12. 실행 계획

### 1단계 — 검증 (영상 10개)

목표는 조회수가 아니라 **수익화 승인 여부 확인**. 여기서 막히면 이후 확장은
무의미하다.

- 계열별 10개 (물 3, 숲 3, 인공 2, 건조 1, 고지 1)
- 며칠 간격 분산 업로드
- 스크립트 1~3 구축

### 2단계 — 선별 확장

- 유튜브 스튜디오 **총 시청 시간** 기준 상위 소재 확인
- 그 소재의 축(날씨/시간대)만 파생
- 반응 없는 계열 폐기

이 장르는 조회수 편차가 극단적이다. 비 오는 소리 하나가 나머지 전부를
합친 것보다 많이 나오는 일이 흔하다.

### 3단계 — 라이브러리 완성

- 그룹 D 영상화
- 그룹 C 확장
- 3/8/10시간 길이 변형 추가

## 13. 별도 검토 — 한국 도시 소리

서울 골목, 지하철, 시장, 카페 등은 **AI로 만들 수 없다.** 합성하면 질감에서
티가 나고, 이 소재를 찾는 사람은 정확히 그 진짜 질감을 원한다.

- 해외 검색 수요 있으나 공급 적음
- 직접 현장 녹음 필수 (폰 녹음기로도 시작 가능)
- 자연음 채널의 유일한 진짜 차별점이 될 수 있음

자연음 채널이 자리 잡은 뒤 별도 시리즈로 검토.
