## 0. 프롬프트 작성 규칙

### 항상 붙이는 안전 문구

```
rounded, low frequency dominant, clearly audible, no sharp transients
```

### 규칙 1 — 약화 키워드를 2개 이상 겹치지 말 것

soft·faint·very sparse·low intensity·silent·still·quiet 를 겹치면 소리가 아예 안 들린다. A08이 soft+low intensity 로 무음화됐고 B17에는 silent 가 들어가 있었다. 강도는 유지하고 날카로움만 뺀다.

| 대신 쓸 것 | 피할 것 |
|---|---|
| `muffled` | `soft` |
| `rounded` | `faint` |
| `warm` | `low intensity` |
| `full` | `silent` |
| `clearly audible` | `still` |
| `audible body` | `quiet` |
| `개수 지정(3-4 hoots)` | `very sparse` |

### 규칙 2 — 정체성을 금지하지 말 것

불은 crackle, 거품은 pop, 모래는 hiss, 대나무는 knocking이다. 본질을 금지하면 아무것도 남지 않는다. 금지가 아니라 완화로 표현한다.

| 잘못 | 올바름 |
|---|---|
| `no pops` | `gentle pops only` |
| `no knocking` | `knocking softly` |
| `no hiss` | `soft rounded low texture` |

### 규칙 3 — 거리감은 볼륨이 아니다

볼륨을 낮춰도 작게 녹음된 가까운 소리일 뿐이다. 거리감은 공기 흡수 + 반향이 만든다.

```
heard from a distance across [공간], long natural reverb, high frequencies absorbed by air
```

### 규칙 4 — 연속성을 원하지 않으면 명시할 것

continuous·steady hum·murmur 는 소리를 통짜 노이즈로 만든다. 액센트 레이어에는 반대로 지시한다.

```
individual calls with long gaps of silence between them, no chorus, no continuous murmur, no dense swarm
```

### 규칙 5 — 배제 키워드

`no metal` `no gravel` `no concrete` `no sharp splashing` `no sharp taps` `no whistling` `no howling` `no shrieking` `no piercing calls` `no snapping`

### 규칙 6 — 히스 계열 공식

물·바람·잎·모래·천은 본질이 고역 화이트노이즈라 그냥 만들면 무조건 날카롭다. no hiss 만으로는 부족하고 거리 + 공기흡수 + 뭉갬 셋이 함께여야 한다.

```
heard from a distance, deep and rounded, high frequencies absorbed by air, muffled, no hiss, no fizz
```

해당: B03 B04 B07 B08 B12 B14 B17 B18 B20 D08

### 규칙 7 — 트랜지언트 계열 공식

불·물방울·시계·종·나무처럼 순간적으로 튀는 소리. 지속음이 아니라 파열음이라 잠들려는 순간에 깨운다.

```
deep and rounded, muffled, gentle onset, long decay, no sharp attack
```

해당: A18 A19 B11 B16 D02 D03 D05 D06 D11 D12

- **D06 종** — `warm fundamental only, no bright overtones, no metallic ring`
- **D07 얼음** — `glassy·crystalline 사용 금지 — 고역을 직접 지시하는 단어다`

### 규칙 8 — 기계음 회피

drone·hum·tone 은 신디사이저 같은 소리를 부른다(B05 사례). 저역 앰비언스는 소재의 물리적 질량감으로 표현한다.

```
thick water body / heavy humid air / deep air pressure, no drone, no machine hum
```

### 규칙 9 — 마찰음은 벽 하나 뒤로

삐걱임·마찰음·똑딱임은 근접하면 무조건 고역이 튄다(B16 사례).

```
heard from another room / heard through a wall
```

**핵심 원리:** 아픈 건 음원이 아니라 부딪히는 표면이다. 프롬프트에 표면과 거리를 반드시 지정한다.

## 그룹 C — 확장 베이스 44장면 88개 (프롬프트 작성 완료)

원안 34장면 + 게임 환경 조사로 찾은 신규 10장면.
각 장면은 베이스(29s) + 서브(23s). 규칙 1~9 적용.

**베이스는 반드시 들려야 한다.** 그룹 D의 29초 배경 4개가 거의 안 들린 사고를
겪었으므로, 모든 베이스에 `clearly audible` 또는 `audible body`를 넣고
규칙 1 약화 키워드(`quiet` 등)를 걷어냈다. "여기가 어디인지" 알아들을
정도로는 나와야 배경음으로 쓸 수 있다.

⚠️ = 고위험. 규칙 6 공식(거리 + 공기흡수 + 뭉갬)이 필수다.
**신규** = 게임 조사로 추가된 장면.
