## 1. 컨셉

"한 사이트에서 모든 툴을 사용해보세요." 추첨·게임·시간·도구 계열 웹 툴을 한곳에 모으고, 상하좌우 광고로 수익을 낸다.

## 2. 디자인

| 항목 | 결정 |
|---|---|
| 테마 | 다크 네온(기본) + 라이트, 헤더 버튼으로 전환, 브라우저에 기억 |
| 모양 | 토스식 — 테두리 없이 면으로 구분, 모서리 8·12·14·16·24px 단계, 세그먼트 컨트롤 |
| 색 | 네온 블루 계열 유지(`#5b74ff`, `#2518b5`, 시안 `#3ee6ff`) |
| 글꼴 | 본문 Pretendard, 숫자 Lilita One (Orbitron 은 7·2 가 ㄱ·ㄹ 처럼 보여 교체) |
| 참고 | OriginKit — 번호뽑기 불꽃공 `Toon fireball 2`, 무대 카드 네온 테두리 `Neon Border` (원본은 `originkit/`) |
| 라이트 모드 | 어두운 무대 없음(연한 파랑 무대), 카드는 얇은 테두리+옅은 그림자, 네온은 normal 겹치기 |
| 이름·주소 | 모아툴 / moatoolbox.com (moatool.co.kr 은 동명 전자공구몰), 툴마다 `/툴id` 주소 |
| 홈 | 툴 카드 한 그리드 |

## 3. 광고

`AdSlot` 한 곳에서 관리. 위·아래 728×90(모바일 320×100), 좌우 160×600(화면 1440px 이상에서만 — 본문 가림 금지 정책).

## 4. 툴 (20종)

| 분류 | 툴 | 핵심 |
|---|---|---|
| 추첨 | 번호뽑기 | 뽑을 때 불꽃공이 한 번 멀리서 다가오며 가로지르고, 이후 꼬리 없는 큰 공 위에 번호를 1.5초 간격으로 하나씩, 0~9999 |
| | 룰렛 | 항목 카드 입력, 당첨 먼저 + 5초 easeOutQuart 감속, 바늘 튕김·틱, 당첨 칸 강조 |
| | 사다리타기 | 말이 5초 안에 도착(구간당 최대 1초), 차례 진행, 사다리 가리기 |
| | 핀볼 뽑기 | 맵 3종(클래식·지그재그·범퍼 숲), 참가자 50명·공 100개·개수 지정, 시작 전 미리보기, 셔플, 꼴찌 당첨, 깔때기 플리퍼 |
| | 팀 나누기 | 룰렛/핀볼 선택, 팀 인원 고르게, 쉼표 이름 |
| | 순서 정하기 | 카드 섞기 → 실제 카드처럼 하나씩 공개 |
| | 제비뽑기 / 당첨 카드 | 종이 펼치기 / 3D 카드 뒤집기 |
| | 주사위 / 코인 | 면이 바뀌다 멈춤 + 달그락 / 금·은 동전, 튕김, 팅·짤랑 |
| 모임 | 자리 배치 / 짝 바꾸기 | 빈자리·고정석 / 지난 짝 피하기(최근 10번) |
| 게임 | 초 맞추기 / 반응속도 | ±0.01초·클리어/블라인드 / 5회 평균, 둘 다 랭킹·최근 탭 |
| 시간 | 타이머 / 스톱워치 / 뽀모도로 | 링 표시 / 랩 / 25·5·15분 자동 이어가기 |
| 도구 | D-day / 카운터 / 글자수 | 1900~2100 자체 달력 / 여러 개 저장 / 공백 포함·제외·바이트 |
