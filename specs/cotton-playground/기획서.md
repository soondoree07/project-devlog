# 그림·소리 채팅앱 — 기획서

*작성일: 2026-08-13 · 최종 갱신: 2026-08-26 · 상태: **베타 범위 확정 — 그리기·랜덤그림·채팅·친구***

> 앱 이름 **솜사탕 놀이터** 확정 / 저장소 `soondoree07/cotton-playground` / 스택 **Flutter**

---

## 1. 한 줄 소개

친구와 채팅하는 앱인데, 앱이 던져주는 **랜덤 사진(동물·사물)** 을 소재로 **따라 그리거나 그 사진이 낼 것 같은 소리를 녹음해** 서로 주고받으며 노는 앱. 말 없이도 통하는 놀이가 핵심이며 **전 연령**을 대상으로 한다.

## 1-1. 출시 단계 (2026-08-25 확정)

먼저 **베타**를 내고 소리는 정식 버전으로 미룬다.

| 단계 | 넣는 기능 |
|---|---|
| **베타** | 그림 그리기 · 랜덤 그림 보내기 · 채팅(텍스트) · 친구 |
| 정식 | 위 + **소리 녹음** |

소리를 뺀 이유는 기능이 덜 됐기 때문이 아니다. 녹음은 이미 실기기에서 동작한다.
**놀이의 절반을 뒤로 미뤄, 먼저 그림만으로 주고받는 재미가 실제로 성립하는지 본다.**

구현은 코드를 지우지 않고 `lib/feature_flags.dart`의 `CottonFeatures.voice`
한 곳으로 껐다. 정식 버전에서 `true`로 되돌리면 녹음 화면·소리 버튼·음성 카드가
그대로 살아난다.

> 베타에서 소리가 빠지므로 아래 4~7장의 "소리" 관련 내용은 **정식 버전 기준**으로 읽는다.

---

## 2. 핵심 재미

> "앱이 사진을 던져주면, 우리는 그림과 소리로 답한다."

한 사람이 그림을 보내면 상대가 그 그림에 어울리는 소리를 상상해 녹음하고, 서로의 상상을 비교하며 웃는 **비대면 캐치볼**. 텍스트 대화가 아니라 그림·소리 교환이 중심이라 언어 부담이 없다.

**핵심 루프:** 앱이 소재(랜덤 사진)를 던진다 → 그림/소리로 답한다 → 서로 감상한다.

## 3. 타깃

전 연령. 유아·아동도 쓸 수 있도록 큰 버튼, 큰 아이콘, 최소한의 글자, 단순한 인터랙션을 지향한다.

---

## 4. 디자인 방향 (확정)

**무드:** 솜사탕 파스텔. 인스타그램 DM "캔디(Candy)" 테마 느낌으로, 하늘색 → 보라 → 핑크로 흐르는 대각선 그라데이션.

**색상 토큰**

| 용도 | 값 |
|------|-----|
| 하늘색 | `#8ECBFF` |
| 핑크 | `#FFB0D8` |
| 포인트 그라데이션 | `135deg, #9FD2FF → #C9B8FF → #FFB0D8` |
| 글자색 | 부드러운 보라 회색 `#5A4A6A` |

**스타일 원칙:** 둥근 모서리 크게, 몽글몽글한 파스텔, 부드러운 그림자.

**디자인 시스템:** 프로젝트에 Nocturne(다크 톤)이 붙어 있으나 앱 무드와 맞지 않아 **사용하지 않고 파스텔 유지**로 확정.

**아이콘 규칙 (중요):** 프로필 사진(아바타)과 실제 기능 버튼의 아이콘만 사용. 제목 옆 장식용·의미 없는 아이콘(예: 타이틀 옆 사탕, 채팅방 우측 상단 캔디)은 넣지 않는다. 아이콘은 눌러서 동작하는 버튼에만 붙인다.

## 5. 화면 구성 (5개)

| 화면 | 이름 | 설명 |
|------|------|------|
| 1 | `list` | 친구 목록. 대화 상대 선택 |
| 2 | `dm` | **메인 채팅.** 텍스트·그림·음성·사진 카드가 모두 말풍선으로 표시 |
| 3 | `draw` | 빈 캔버스 그리기 (브러시 굵기·팔레트·지우개·되돌리기). 완료 시 그림이 채팅으로 전송 |
| 4 | `record` | 녹음 (최대 10초, 실시간 파형, 타이머). 완료 시 음성 카드로 전송 |
| 5 | `settings` | 설정 (내 코드·친구추가·내 정보 등) |

## 6. 인터랙션 동작 (확정)

**DM 하단 입력 영역**
- 키보드 닫힘 상태: **그리기 · 랜덤사진** 두 버튼 노출
- 키보드 열림 상태: 두 버튼 숨김 + 시스템 한글 키보드 노출 (123 · 언어토글 · **전송키**)
- 스크롤하거나 키보드를 드래그해 내리면 입력창이 한 줄로 축소되고 우측에 원형 아이콘 버튼

**랜덤 사진**
- 전용 화면 없이 **버튼을 누르면 항상 랜덤 사진이 즉시 카드로 전송** (카테고리 선택 없음)

**그리기 / 녹음**
- 참고 이미지 없는 **백지 상태**에서 시작, 뒤로가기로 채팅 복귀
- `draw` 완료 → 그림 카드 전송 / `record` 완료 → 음성 카드 전송

**공통**
- 전송·새 메시지 시 자동 스크롤
- 스크롤바는 전부 숨김

**키보드 설정**
- 자체 키보드를 만들지 않고 **시스템 기본 키보드** 사용 (테마 자동 적용은 OS 보안상 불가)
- 입력칸 **리턴키 = 전송(Send)**. 엔터 시 바로 전송, 여러 줄 입력은 전제하지 않음

## 7. 기능 전체 지도

```

│
├─ 채팅 ────────── 친구별 대화방 · 그림/음성/사진 카드 말풍선 · 자동 스크롤
```

## 8. 구현 현황 & 남은 작업

### 완료 (2026-08-13, Flutter 실기기 검증)

**화면 6개** — 대화 목록 · 대화방 · 그리기 · 녹음 · 친구 목록 · 설정

- 대화방: 텍스트·그림·음성·랜덤사진 카드, 키보드 연동, 자동 스크롤
- **그리기 실동작** — 팔레트 6색·붓 3단계·지우개·되돌리기, 740x740 PNG로 전송
- **녹음 실동작** — 마이크 권한 요청, m4a 녹음, 실시간 파형(실제 입력 크기 기반), 최대 10초, 카드 재생
- **친구 목록 보기·삭제** (확인창 + 빈 상태) — 기존 "설정 화면 미구현" 2건 해소
- 랜덤사진 탭 즉시 전송 (소재는 아직 단어 자리표시)
- 반응형: 화면 폭 320~480dp · 글꼴 배율 1.0~2.0 대응, 126조합 자동 검증

### 베타에서 뺀 것 (2026-08-25)

- **소리 녹음** — `CottonFeatures.voice = false`. 대화방 소리 버튼(원형·큰 버튼 양쪽),
  예시 대화의 음성 카드가 감춰진다. 화면·서비스 코드와 테스트는 그대로 남아 있다
- 함께 손본 문구 — 대화 목록 안내 · 친구 삭제 확인창 · 랜덤 사진 카드 설명에서 "소리"를 뺐다
- **남는 문제** — `record`·`audioplayers` 의존성이 그대로라 베타 APK에 `RECORD_AUDIO`
  권한이 들어간다. 스토어 데이터 안전 섹션 기입이 필요하고, 걸리면 그때 의존성을 뺀다

### 아직 가짜인 것
- **랜덤 사진 실제 이미지** — 소재 118개 목록 확정, 이미지 47장 생성 (`docs/사진목록.md`)
- 친구 목록·내 코드는 고정값 (서버 없음)
- 받은 예시 메시지의 음성은 파일이 없어 진행률만 흉내

### 꼭 필요한데 빠진 부분 (우선순위)

**1순위 — 없으면 핵심 루프가 안 돎**
- **친구 연결 흐름**: 내 코드 보기 → 상대가 코드 입력(또는 QR) → 연결. 아는 사람만 코드로 연결(무작위 매칭 없음)
- **받는 쪽 상호작용**: 받은 음성 카드 **재생**, 받은 그림 **크게 보기** (감상·리액션 절반이 여기)
- **마이크 권한 요청**: 최초 녹음 시도 시 권한 팝업 (없으면 녹음 자체가 불가)
- **랜덤 사진 실제 풀**: 메인 놀이 소재

**2순위 — 출시 전 필수 (안전·최초경험)**
- **알림(새 메시지)**: 시간차로 주고받는 비대면 놀이라 알림이 없으면 앱이 죽음
- **신고 / 차단**: 전 연령 대상, 사용자 생성 그림·음성 대응
- **온보딩**: 최초 실행 시 닉네임·프로필 설정, 권한 안내
- **빈 상태 화면**: 친구 없을 때 / 대화 없을 때 안내

## 9-1. 정식 버전으로 미룬 것

### 소리 녹음

베타에서 뺐다. 기능이 덜 돼서가 아니라, **그림만으로 주고받는 재미가 성립하는지
먼저 보려는** 판단이다. 자세한 내용은 위 1-1절.

### 색 채우기 (2026-08-26 보류)

Procreate처럼 **사방이 막힌 곳에 색을 끌어다 놓으면 채워지는** 기능. 색칠하는
재미가 크게 늘어나므로 정식 버전에서 넣는다.

미룬 이유는 **그리기 방식 자체를 바꿔야 하기 때문이다.** 지금은 그림을 "어디서
어디로 이만한 굵기로 그었다"는 선의 목록으로 들고 있는데, 색 채우기는 점 단위로
번져 나가는 작업이라 선 목록으로 표현할 수 없다.

바꿀 방향은 이렇다.

- 지금까지 그린 것을 **그림판 한 장으로 구워 두고** 그 위에 새 선을 얹는다
- 색을 떨어뜨리면 그 그림판에서 같은 색 영역을 찾아 칠한다
- **되돌리기**를 이전 그림판을 쌓아 두는 방식으로 바꿔야 한다

부수 효과로 그림이 많아져도 느려지지 않는다. 다만 **지금 잘 되는 그리기와
지우개가 깨질 위험**이 있어, 베타를 내보낸 뒤 여유 있을 때 손댄다.

## 10. 결정 사항 로그

- 타깃: 전 연령
- 무드: 솜사탕 파스텔(하늘색+핑크), Nocturne 미사용
- 아이콘: 프로필·기능 버튼만, 장식 아이콘 금지
- 키보드: 시스템 기본 사용, 리턴키 = 전송
- 랜덤사진: 카테고리 제거, 버튼 탭 시 항상 랜덤 전송
- 소리→그림 역방향 모드: 제외
- 출시 형태: **네이티브 앱으로만 출시** (웹앱 아님)
- 디자인 도구: 클로드 디자인 사용

### 2026-08-13 추가 결정

- **앱 이름: 솜사탕 놀이터** (`cotton-playground`)
- **기술 스택: Flutter 확정.** 디자인이 쓴 그라데이션·블러·줄무늬·캔버스가 Flutter는 전부 기본 내장이라 추가 의존성 0으로 재현된다. React Native는 라이브러리 4개가 필요하고 안드로이드 블러가 불안정. 백엔드는 Firebase 예정
- **디자인 시안은 어느 스택으로도 그대로 못 쓴다.** `.dc.html`은 클로드 디자인 전용 포맷이라 값을 옮기는 작업이 필요하다. 옮긴 값은 `lib/theme/cotton_tokens.dart`에 보관
- **하단 입력 영역** — 키보드 닫힘: 입력칸 옆 원형 버튼 3개(랜덤사진·그리기·소리) / 키보드 열림: 큰 버튼 3개가 키보드 위로 올라가고 입력칸 옆은 전송 버튼
- **시스템 키보드의 마이크는 받아쓰기(음성→텍스트)라 녹음에 쓸 수 없다.** 녹음 진입로는 앱이 직접 들고 있어야 한다
- 글꼴 확대는 1.2배까지만 따른다 (그 이상은 레이아웃이 무너짐)
- iOS는 폴더만 준비. **빌드하려면 맥이 필요하다**

### 2026-08-17 추가 결정

- **랜덤 사진 소재는 사진이 아니라 AI로 생성한 통일 그림체 일러스트로 간다.** 아이가 크레용으로 그린 낙서풍, 흰 배경, 정사각형 1024x1024
